## Overview

Three Android apps cover the key on-site operations — entry scanning, ticket sales, and point-of-sale. All three authenticate with the same admin credentials used for the web dashboard and support Sunmi hardware (printers, cash drawers, NFC readers). Box Office Pro and EPOS Pro integrate with Stripe Terminal for card payments.

## Shared Capabilities

| Capability | Description |
|------------|-------------|
| **Admin login** | All apps use the same email and password as the admin dashboard. Permissions control what each staff member can access. |
| **Stripe Terminal** | Card payments in Box Office Pro and EPOS Pro via Bluetooth or USB Stripe readers, or Tap to Pay on the device. Each app has its own reader setup — see [Box Office Pro](/mobile-apps/box-office-pro/settings-and-hardware#stripe-card-reader) and [EPOS Pro](/mobile-apps/epos-pro/settings-and-hardware#stripe-card-readers). |
| **Sunmi hardware** | Receipt printing, cash drawers, and built-in NFC on supported Sunmi devices. |
| **NFC support** | Read NFC wristbands, cards, and badges for entry, [ticket pairing](/user-manual/event-management/nfc-pairing), and identifying customers for cashless payments. The apps read only the tag's ID — balances and ticket details are held on the platform, so nothing is written to the tag. |
| **Second screen** | On dual-screen devices, a customer-facing display shows basket contents, totals, and payment prompts. |
| **White-label branding** | Logos, colours, and gradients can be customised per company. |
| **Offline operation** | Access Control Pro supports full offline mode. EPOS Pro and Box Office Pro need a connection to complete sales — see [EPOS Pro connectivity](/mobile-apps/epos-pro/introduction#connectivity-and-data-sync). |

## Configuration

Each app has its own settings screen for toggling payment methods, connecting hardware, and enabling optional features. The admin panel also controls what's available to the apps — for example, EPOS shops and products are configured in the [EPOS settings](/user-manual/epos/overview), while event access zones are set up in [access control configuration](/user-manual/event-management/access-control).
