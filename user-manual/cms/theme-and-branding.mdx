## Overview

Theme and branding settings define the visual identity of your ticket shop. From colour scheme and typography to logo placement and footer layout, these settings shape every page your customers see.

Configuration is split across two areas in admin:

- **Company branding** — your colour theme and logos
- **Shop theme** — detailed styling for fonts, buttons, menus, footers, default images, and announcements

## Colour Theme

Your colour theme sets the primary colour palette used throughout the shop — for buttons, links, badges, navigation highlights, and other UI elements.

### Preset Themes

Choose from 11 preset colour themes:

| Theme | Description |
|-------|-------------|
| **Grey** | Neutral grey tones |
| **Cool Grey** | Cool-toned grey |
| **Red** | Red accent colour |
| **Orange** | Orange accent colour |
| **Yellow** | Yellow accent colour |
| **Green** | Green accent colour |
| **Teal** | Teal accent colour |
| **Blue** | Blue accent colour |
| **Indigo** | Indigo accent colour |
| **Purple** | Purple accent colour |
| **Pink** | Pink accent colour |

### Custom Colours

Select **Custom** to define your own colour values. Custom colours give you full control over the palette used across the shop.

## Logos

Upload logos that appear in your shop's navigation and branding areas. Multiple logo variants ensure your branding looks correct against different backgrounds.

| Logo | Purpose |
|------|---------|
| **Default logo** | The primary logo used in the shop |
| **Dark logo** | Used on light backgrounds where the default logo may not have enough contrast |
| **Light logo** | Used on dark backgrounds (e.g. when the menu overlays a dark header image) |
| **Favicon** | The small icon shown in browser tabs (cropped to 32x32 pixels) |

### Logo Display

Control where your logo appears:

| Option | Behaviour |
|--------|-----------|
| **Main menu** | Logo is displayed in the main navigation bar |
| **Top menu** | Logo is displayed in the top bar above the main navigation |
| **Hidden** | Logo is not displayed in the navigation |

You can also enable **logo in footer** separately to show your logo in the footer area.

## Fonts

Customise the typography used across your shop:

| Setting | Controls |
|---------|----------|
| **Heading font** | Font family and weight for headings throughout the shop |
| **Body font** | Font family and weight for body text and general content |

Choose from available font families and select a variant (weight) for each. You can enable multiple fonts, though a warning appears if you have many fonts active — each additional font adds to page load time.

<Note>
Fonts that are currently in use cannot be removed. To remove a font, first switch any settings that reference it to a different font.
</Note>

## Buttons

Configure the appearance of buttons throughout your shop:

### Button Shape

| Shape | Description |
|-------|-------------|
| **Sharp** | Square corners with no rounding |
| **Smooth** | Slightly rounded corners |
| **Slightly round** | Moderately rounded corners |
| **Round** | Well-rounded corners |
| **Pill** | Fully rounded, capsule-shaped buttons |

### Button Text Format

| Format | Description |
|--------|-------------|
| **None** | Text displays in its natural case |
| **Capitalise** | First letter of each word is capitalised |
| **Lowercase** | All text in lowercase |
| **Uppercase** | All text in uppercase |

### Primary and Secondary Button Styles

Both primary and secondary buttons can be configured independently:

| Setting | Description |
|---------|-------------|
| **Button style** | Choose between filled (solid background) or line (outlined) |
| **Button colour** | The background or border colour |
| **Button text colour** | The colour of the text label |

## Menu Styling

Fine-tune how the navigation menus appear:

| Setting | Description |
|---------|-------------|
| **Menu theme** | Choose between **Default** or **Gray** menu styling |
| **Main menu text** | Text colour settings for the main navigation bar |
| **Top menu text** | Text colour settings for the top bar |
| **Menu dividing lines** | Show or hide lines between menu sections |
| **Menu position** | Whether the menu sits **above** or **covers** full-width header images — this works best with menus that have some opacity |
| **Opacity over images** | The menu's transparency level when overlaying header images |

<Note>
The menu position setting only affects pages that use a full-width header image style. On pages without a header image, the menu always appears above the content.
</Note>

## Footer

Configure the footer area that appears at the bottom of every page:

### Footer Layout

Choose from 10 layout options to match the number and arrangement of your footer content:

| Layout | Description |
|--------|-------------|
| **4 Columns (centered)** | Four equal columns, centered |
| **3 Columns (centered)** | Three equal columns, centered |
| **List** | Items displayed as a vertical list |
| **Centered** | Content centered in a single area |
| **Left aligned** | Content aligned to the left |
| **Right aligned** | Content aligned to the right |
| **6 Columns (centered)** | Six equal columns, centered |
| **3 Columns (left)** | Three columns, left-aligned |
| **4 Columns (left)** | Four columns, left-aligned |
| **6 Columns (left)** | Six columns, left-aligned |

Choose a column count that matches how many groups of links you intend to show. For example, if you have 3 or 6 footer menu items, a 3-column layout works well.

### Footer Options

| Setting | Description |
|---------|-------------|
| **Footer colour** | Background colour of the footer area |
| **Footer dividing lines** | Show or hide lines between footer sections |
| **Enable logo in footer** | Display your logo in the footer |
| **Footer imprint** | Custom text displayed in the footer (e.g. legal information, company details) |

## Default Images

Default images fill the gap whenever an event, schedule, or item doesn't have an image of its own, so your shop never shows an empty image space. They're managed in the **Event page options** section of your theme settings (**Website** > **Site settings** > **Theme**).

### Setting A Company Default Image

<Tip>Company default image added in Release 48</Tip>

Upload a **Default image** to set a single fallback for your whole site. It's used by default for every image field that doesn't have its own image — event thumbnails and headers, schedule headers, and item images such as tickets, products, donations, and gift vouchers — across the shop and admin. One upload is enough to give every event and item a branded image.

The image must be at least 600 × 300 pixels and no more than 1800 pixels wide, in a 2:1 aspect ratio. As with the other default images, you can use the language switcher to upload a different version for each of your [languages](/user-manual/core/translations).

### Overriding Individual Defaults

Click **Show advanced image settings** to set a different default for a particular type of image. Each one replaces the **Default image** for that image type only:

| Default | Used for |
|---------|----------|
| **Thumbnail image** | The image displayed for your event on listing pages and in search results |
| **Header image** | The banner displayed at the top of your event page |
| **Event sharing image** | The image displayed when an event page is shared on social media. Each event can have its own sharing image that overrides this setting. |
| **Schedule heading image** | The image displayed at the top of the schedule listing page |
| **Item image** | The image displayed for items throughout the shop when no specific item image has been uploaded |

While a **Default image** is set, any of these fields left empty shows the default image with the label **Inherited from default image**. If you don't want a particular image type to use your default image, remove the inherited image from that field — that image type then shows the platform's placeholder image instead. Uploading an image to the field replaces the placeholder again.

The advanced settings also include **Remove image aspect ratio restriction**, which lifts the 2:1 requirement for event and schedule images, including the **Default image**. Allowing any aspect ratio can disrupt the event page layout, especially on mobile, so only enable it if you're certain your images will still display well.

### Which Image Is Shown

For each image, the platform uses the first of these that is available:

1. The image uploaded to the individual [event](/user-manual/event-management/event-page-customisations#images), [schedule](/user-manual/event-management/schedules), or [item](/user-manual/sale-items/core-concepts)
2. The matching individual default from the advanced image settings
3. The **Default image** — unless its inherited image has been removed for that image type
4. The platform's placeholder image

<Note>
Emails and social media link previews don't fall back to the **Default image**. Event images in emails use the **Thumbnail image** default, and [link previews](/user-manual/core/seo#fallback-behaviour) use the **Event sharing image** default, before falling back to the platform placeholder. Upload these individually if you want your own image to appear there.
</Note>

## Seating Colour Palettes

<Tip>New in Release 47</Tip>

If you use [seating plans](/user-manual/seating-plans/introduction), you can control the colours used to show seat statuses on the plan — both for customers in the shop and for staff managing seating. These colours are configured under **Seating options** in the theme settings.

### The Default Palette

Every shop has a built-in **Default colour palette**. It defines a colour for each seat status and cannot be renamed, recoloured, or deleted. You can use it as-is, or add your own palettes alongside it.

### Adding A Palette

Click **Add colour palette** to create a new palette. Each palette has a **Label** to identify it, and a colour for each seat status. Set each colour with the colour picker. You can add several palettes and delete any palette you have added (the default palette stays).

A palette defines these colours:

| Status               | Where it shows                          |
| -------------------- | --------------------------------------- |
| **Available**        | Shop and admin                          |
| **Unavailable**      | Shop and admin                          |
| **Accessible spaces**| Shop and admin                          |
| **Reserved**         | Admin only                              |
| **Booked**           | Admin only                              |
| **Restricted**       | Admin only                              |
| **Season ticket**    | Admin only                              |

<Note>
  Statuses marked **Admin only** are never shown to customers in the shop — they only colour the [event plan dashboard](/user-manual/event-management/seated-events#plan-dashboard) used to manage seating.
</Note>

<Note>
  By default, price band colours are displayed for available seats. This can be switched off per seating plan under price band settings, in which case the palette's **Available** colour is used instead.
</Note>

### Choosing Which Palette To Use

Two settings decide which palette applies where:

| Setting                                  | Effect                                                                                                                   |
| ---------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| **Shop seating colour palette**          | The palette customers see when selecting seats in the shop.                                                              |
| **Default admin seating colour palette** | The palette staff see by default on the event plan dashboard. Staff can switch to a different palette for their own view. |

A live preview shows how the focused palette looks. Use the **Shop** / **Admin** toggle to preview each context, and **Randomise preview bookings** to see how the colours read across different seat statuses.

## Announcements

Display a banner message above the navigation on every page of your shop. Announcements are useful for important notices like maintenance windows, special promotions, or general information.

### Configuring an Announcement

Announcements are managed within the shop theme settings:

| Setting | Description |
|---------|-------------|
| **Show menu announcement** | Toggle the announcement banner on or off |
| **Announcement content** | The message displayed — supports rich text and HTML |
| **Announcement colour** | Background colour of the announcement banner |
| **Announcement padding** | Vertical spacing around the announcement content |

When enabled, the announcement banner appears above the top menu across all shop pages.
